# 管理面板

左侧六个页面：首页、系统配置、Tunnel 列表、API 凭证、运行日志、用户管理、关于。

## 首页

一眼看清现状：**在线隧道数 / 隧道总数 / 边缘连接数 / 运行时长**，下面是隧道卡片一览（名称、域名、本地服务、在线状态）。

尚未配置 Cloudflare 凭据时，顶部会提示并给出教程入口。

## Tunnel 列表

这是最常用的页面。

### 创建与启停

| 操作 | 说明 |
|---|---|
| **新建 Tunnel** | 输入名称即可，会在 Cloudflare 云端创建隧道（不会自动建 DNS） |
| **连接 / 断开** | 单条隧道独立进程，**多条可以同时在线** |
| **自启开关** | 打开后容器重启会自动重连（相当于开机自启） |
| **删除** | 同时清理本地进程与云端隧道 |

每条隧道会显示两个可点击的链接：

- **域名：** `https://nas.example.com` —— 新窗口打开你的服务
- **本地：** `http://192.168.1.10:5000` —— 新窗口打开内网地址（在 NAS 所在网络内可用）

### 路由规则

点「路由」配置「域名 → 内网服务」的映射：

| 字段 | 说明 |
|---|---|
| 域名 | 要暴露的公网域名，如 `nas.example.com` |
| 服务 | 内网地址，如 `http://192.168.1.10:5000` |

保存后会自动在 Cloudflare 创建 **DNS CNAME** 记录（橙云代理），所以：

- 边缘自动提供 **HTTPS**，不用自己申请证书
- 隐藏了你的真实出口 IP

::: tip 同一个内网服务可以挂多个域名
一条隧道的规则列表里可以加多条规则，指向同一个内网服务。所以「随机域名 + 自定义域名」同时挂在一个服务上完全没问题——这正是调试期常用的做法：随机域名用来临时验证，跑通了再换成正式域名。
:::

### 随机子域名

先在「**系统配置 → 默认域名**」里填好主域名（如 `example.com`），之后在路由弹窗里点「**🎲**」就能生成一个随机二级域名。

生成的是「随机词 + 你的域名」形式，而不是一串纯数字，看着更像正常站点。

## 设备识别与分组

如果你在**多台设备**（例如服务器1、服务器2、NAS3）上装了同一个账号，隧道列表会自动按设备归类：

- 顶部有一条**筛选标签栏**，第一行是**设备**（🏠 本机 / ☁️ 其他设备）
- 第二行是**分组**（默认「未分组」）
- 点标签即可筛选，再点一次取消

分组名和设备显示名都可以自己改：

- **改设备显示名**：「系统配置 → 本设备名称」
- **改分组名**：在筛选条上点分组标签旁的编辑按钮，会把这个分组下所有隧道一起改名

::: info 为什么能看到其他设备的隧道？
隧道信息存在 Cloudflare 云端，所有用同一账号凭据的面板都会看到全量列表。「本机 / 其他设备」标记是根据进程实际运行的位置判断的——本机跑着的隧道才能真正操作。
:::

## 用户管理

> 仅管理员可见。

- **审核注册**：新用户注册后处于待审核状态，管理员通过后才能登录
- **启用 / 禁用**：禁用会**立即踢下线**（当前会话失效）
- **重置密码 / 删除用户**
- **备注**：给用户加个说明（例如「客厅笔记本」「老爸的手机」），仅管理员可见
- **注册开关**：关闭后登录页不再显示注册入口

普通用户能做什么：查看和操作**自己的**隧道，看不到其他用户创建的隧道，也进不了用户管理和 API 凭证页。

### 忘记管理员密码

在 NAS 上给容器加环境变量 `ADMIN_PASSWORD`，然后：

- 用户名填 `master` 或留空，密码填 `ADMIN_PASSWORD` 的值
- 登录后可在用户管理里重置任意用户密码

## 系统配置

分三块：

| 卡片 | 内容 |
|---|---|
| **站点设置** | 站点名称自定义、禁止搜索引擎收录开关 |
| **Cloudflare 账号** | Account ID、API Token（测试连接后保存）、折叠的获取教程 |
| **连接参数** | 连接协议（QUIC / HTTP2）、边缘 IP 版本（IPv4 / IPv6）、默认域名 |

### 站点设置

- **站点名称**：改这里会同步更新浏览器标签页标题、侧边栏品牌名、登录页标题。最长 32 字，留空恢复默认。
- **禁止搜索引擎收录**：默认开启，详见 **[安全与公网暴露](/guide/security#三层反收录)**。

### 连接参数怎么选

| 参数 | 建议 |
|---|---|
| 协议 | 默认 `QUIC`（UDP）。若网络屏蔽 UDP 导致连不上，改成 `HTTP2` |
| 边缘 IP 版本 | 默认 `IPv4`。纯 IPv6 环境选 `IPv6`，不确定留 `auto` |
| 默认域名 | 填你的主域名，用于一键随机子域名 |

## 运行日志

每条隧道独立日志区，支持：

- 关键字过滤
- 自动刷新开关
- 异常退出时**真正的错误行会被提取置顶**，不用在几十行日志里翻

## 关于

- **项目信息**：版本号、提交号、运行环境、数据目录、面板目录、仓库链接
- **版本更新**：检测更新 → 手动确认 → 一键更新（详见 **[更新与国内加速](/guide/update)**）
- **更新源设置**：默认已内置国内镜像自动切换，一般无需修改
