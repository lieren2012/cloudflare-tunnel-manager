☁️ Cloudflare 账号

📖 怎么拿 Account ID 和 API Token？（3 步，1 分钟）
  1. 第 1 步 · 复制 Account ID：打开 dash.cloudflare.com → 首页右侧栏找到「账户 ID / Account ID」→ 点复制按钮（一串 32 位字符）
  2. 第 2 步 · 创建 API Token：打开 API 令牌页面 → 「创建令牌」→ 拉到最下面选「创建自定义令牌」→ 在「权限」处依次添加下面 2 条权限（每条权限 = 三个下拉框：权限类型 → 具体权限 → 级别）：
    ① 权限类型② 具体权限③ 级别（选「编辑」）
    账户 AccountCloudflare Tunnel编辑 Edit
    区域 ZoneDNS编辑 Edit
    （「编辑」就是第三个下拉框「级别」里的选项，英文界面叫 Edit；注意是「DNS」不是「DNS 设置」）
    区域资源选你的域名 → 「继续以显示摘要」→ 「创建令牌」→ 立刻复制令牌（只显示这一次）
  3. 第 3 步 · 填进面板：把两串字符分别填到下面「账号 ID」和「API 令牌」两个框 → 点「测试配置」显示通过 → 点「保存配置」

⚠️ 不要用「Global API Key」（全局密钥权限过大）；填错最常见的原因是令牌没复制全、或权限少给了 DNS。 查看完整教程与常见问题 →

令牌需授予 Cloudflare Tunnel（读取+编辑） 与 DNS（读取+编辑） 权限。
