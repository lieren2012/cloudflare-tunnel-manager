常见问题 ​

新装桌面端一直“初始化本地服务”？ ​

v1.8.0 历史小体积包没有完整运行资源，不能靠等待解决。请关闭旧程序，安装 v1.8.1 对应平台的包。v1.8.1 本地服务就绪后才显示窗口；仍失败请检查应用数据目录的 service.log，不要重复注册。

登录账号是 Cloudflare 账号吗？ ​

不是。面板账号保存在这次安装的 data 中。新目录首次创建管理员，已有目录登录原账号；新用户注册需管理员审核。Docker 与桌面数据不自动同步。

桌面端会自动启动我本地的网站吗？ ​

不会。它启动本地管理服务和 cloudflared。要转发的网站/接口必须先启动，并让运行 Tunnel 的设备能访问。

为什么桌面没有 19090 端口？ ​

桌面端监听 127.0.0.1，动态选择端口，见 service.log。Docker 默认固定为 19090/19092/19093；桌面窗口就绪后自动打开正确的本地地址。

Docker 升级后又让注册？ ​

通常是项目目录或 data 挂载变了，不能据此断定数据已删除。先 docker inspect cf-tunnel-manager 核对 /app 和 /data 的挂载源；找到旧 data、备份后再恢复。不要直接删数据。

更新源 404 或地址套了两层？ ​

按更新教程还原 origin。Git 加速前缀与 Docker 镜像地址不能混用；清空自定义前缀并选“自动”。

cloudflared 一连接就断开？ ​

核对 Account ID/Token 权限、云端隧道是否存在、转发地址是否可达，并查看运行日志。网络不支持 UDP 时可尝试 HTTP2，不能保证切换协议一定解决线路问题。

云端在线、本地离线？ ​

可能是别的设备还运行着该隧道，或本机未连上。核对本地进程、连接日志和公网真实请求，不能仅看一个状态字段。

同一隧道可以运行多个副本吗？ ​

Cloudflare 官方支持，每隧道最多 25 个活跃副本。但副本可能分别收到请求，需要配置一致、业务服务均可达；不要把副本误用于随机切换到不同业务服务。来源：账户限额。

免费 Tunnel 只能 200 个请求吗？ ​

200 个同时处理中请求是临时 Quick Tunnel 的限制，不适用于本面板通过账户创建的命名隧道。完整限制和来源。

大文件上传或视频播放能保证吗？ ​

不能。公网 Free 套餐一次 HTTP 上传上限为 100 MB，视频/大文件分发另受条款约束。分块、超时、应用和线路也会影响结果。项目没有公布实测吞吐或大文件验收，详见限制。

删除/卸载是否删除 Cloudflare 配置？ ​

卸载桌面程序或 Docker 容器不等于删除 Cloudflare 云端隧道/DNS。面板删除隧道会涉及云端资源，DNS 清理行为需另外核对；先备份和确认目标。

忘记 Docker 管理员密码？ ​

可为容器配置临时 ADMIN_PASSWORD，重建后用 master（或留空用户名）与临时密码进入，再重置正式账号。完成后移除临时入口。桌面端没有对应的图形化紧急恢复入口，不要直接套用 Docker Compose 教程。

程序会把什么发给 Cloudflare？ ​

本地保存账号、配置和凭据；调用 Cloudflare API 管理隧道/DNS 时会发送相应 Token、账户和配置，业务请求通过 Tunnel 经过 Cloudflare。不能说“所有信息永远不离开本机”。日志和备份上传前必须脱敏。

报告问题 ​

在 Issues 提供版本、系统/架构、操作步骤和脱敏错误日志。不要提交密码、Token、Cookie 或 data 备份。
